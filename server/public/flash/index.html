FakeWiFi PRO Firmware Flasher

Работает в Chrome/Edge на компьютере. Подключите ESP32 по USB, нажмите кнопку установки, выберите COM-порт и подтвердите прошивку.

Цель: ESP32, схема разделов без OTA (увеличенный APP).

  1. Откройте эту страницу в Chrome или Edge на Windows/macOS/Linux.
  2. Подключите плату USB-кабелем с передачей данных.
  3. Нажмите Установить прошивку.
  4. Выберите нужный последовательный порт.
  5. Дождитесь завершения прошивки и проверки.

Если устройство не определяется, зажмите кнопку BOOT при подключении или в момент старта прошивки.
